1.  [**Keyboard shortcuts**](https://usethekeyboard.com)

⌨️ I'm not a big one to memorizing shortcuts. I have my shortcut selection and it takes me forever to get used to a new one.

But I know there are people that love shortcuts. It is a great way to improve productivity. Not having to drag the mouse around to find the right menu option. Press a few key combinations and you are done!

This is a site where you can find **lists of most useful shortcuts** for various applications on Mac and Windows. My favorite lists: Evernote and Visual Studio Code (by the way, this is NOT the same as Visual Studio).

2.  [**Lazy loading**](https://daiveedjay.hashnode.dev/implementing-image-lazy-loading-to-improve-website-performance-using-javascript)

🦥 Lazy loading is a technique in web development where **the loading of resources is postponed on a page until they are needed**, rather than loading them immediately after the page loads. This improves the user experience.

This article will show you how to do it with Images, JavaScript, and CSS. Even if you don't work with this, it is good to be able to talk about what lazy loading means.[  
    ](https://martinfowler.com/tags/domain%20driven%20design.html%5D.￼)
