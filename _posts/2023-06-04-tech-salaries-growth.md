Today I bring to you malware, content writing, and React.

1.  [**The Dangers of Google's new .ZIP Domains (TLD)**](https://medium.com/@bobbyrsec/the-dangers-of-googles-zip-tld-5e1e675e59a5)

☣️ TL;DR; Be careful if you receive links that contains .ZIP - They can be malware disguised as legit links.

It is becoming harder and harder for us, common humans, to catch malware/scam email. Scammers and bad actors are becoming more sophisticated with their strategies.

I used to be able to detect a suspicious link just by looking at it. Now it is no longer that easy cause the link can have characters that are not easy to recognize.

This article talks about that. It becomes a bit TOO technical but it is a good warming call for all of us.

2.  [**SEO For Tech Content**](https://dx.tips/seo-content-engine)

🔎 SEO stands for "Search Engine Optimization". It is a set of strategies that can help to make content more attractive to Google.

As mentioned before, I'm a big proponent of developers having blogs and focusing on using it as a learning tool that can help their career.

Although I don't recommend obsessing over trying to make their blog popular, because it can be a receipt for frustration, they can use some simple tactics as they put technical content together that can increase their chances of getting some natural SEO exposure.

This article provides a bunch of strategies to make tech content stand out on Google Search.

3.  [**Why React Renders**](https://ui.dev/why-react-renders)

🤓 People ask me all the time "What should I learn that will help me get a job as a developer". If you intend to be a web developer, React is a must.

But React can be a bit tough to understand. This article provides a very simple overview of how React works from a high-level. Start there, and then you can dig into the details.
