2.  [**Alt Text**](https://www.a11yproject.com/posts/are-you-making-these-five-mistakes-when-writing-alt-text/)

♿️ Alt text is the HTML image property that describes the image that you see on a site. This is useful for screen reader users that rely on a program reading the page for them, instead of seeing the content.

It is also legally necessary as there are legislations that mandate website accessibility.

This article points out a few things that you should have in mind when creating alt text properties. Use it on your portfolio sites, when adding images.
