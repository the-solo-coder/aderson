3.  [**BFF**](https://www.youtube.com/watch?v=SSo-z16wEnc)

🤝 No, I'm not talking about "Best Friends Forever". I'm talking about "A Backend For A Frontend" (BFF) Architecture Pattern.

This architecture pattern is a design approach used in software development, especially in the context of web applications and services.

This pattern involves creating a unique backend service layer tailored specifically for each type of frontend application that a system has to support.

This short video will give you a better idea of what this is and you can go a bit deeper with [this article](https://medium.com/mobilepeople/backend-for-frontend-pattern-why-you-need-to-know-it-46f94ce420b0).
