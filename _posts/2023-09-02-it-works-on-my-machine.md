3.  [**It works on my machine**](https://medium.com/zero-equals-false/docker-introduction-what-you-need-to-know-to-start-creating-containers-8ffaf064930a)

🙌 If you have a little experience in tech you must have said or heard someone saying the phrase *"It works on my machine"* when developers face the situation that their code doesn't run on a live environment. I said that myself before!

That is where Docker comes in. Dockers is a container technology that promises to ship code and environment together some no dev can say this phrase again.

I had to get myself familiarized with Docker in the last few days as it is a technology used by the company I'm interviewing for.

Read this article to, at least, know what docker is all about. No need to go too deep unless you have to.
